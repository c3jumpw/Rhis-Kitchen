Deploy & Publish
1
Download the app file — click the Deploy button at the top right. This generates a single .html file with your current menu and settings baked in.
2
Go to netlify.com/drop — drag your ree-kitchen.html file onto the page. It goes live in under 30 seconds.
3
Rename your URL — in the Netlify dashboard click "Site settings" → "Change site name" → set it to something like ree-kitchen → your URL becomes ree-kitchen.netlify.app.
4
Share the link with admins. Anyone with the URL can use the app on any device — phone, tablet, laptop. No login needed unless you set a PIN below.
5
To update the app — make changes here, re-download, drag the new file to Netlify. It replaces the old version at the same URL automatically.
