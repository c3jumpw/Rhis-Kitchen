PAYMENT INTEGRATION
Coming soon
Payment will be handled through Zapier — no payment keys are ever stored in this app or in the public GitHub repo. When an order is placed, Zapier receives the order data and can trigger a Stripe payment link, Cash App request, or Square invoice via the Zap 1 workflow.
Option A — Zapier + Stripe
Zap 1 creates a Stripe Payment Link for the order total and sends it to the customer via Twilio SMS. Customer pays via link. Stripe confirms back to Zapier which updates order status to Confirmed.
Option B — Public order form
A separate customer-facing order page (hosted on GitHub Pages or Squarespace) with a Stripe checkout. On payment, a Zap fires to ClickUp + this OMS. Jeffrey and Rhi see the order appear automatically.
Option C — Jeffrey's existing account
If Jeffrey's business account (Cash App Business, Square, or Zelle) generates shareable payment links, Zap 1 can include that link in the order confirmation SMS. Simplest to activate.
When to activate
Confirm Jeffrey's payment account type → set up Twilio + SendGrid → add a payment action to Zap 1. No changes to this app file needed — Zapier handles it all.
⚠ Never paste your Stripe secret key here. Only the public key (starts with pk_) is safe in a browser. Secret keys belong in Zapier only.
